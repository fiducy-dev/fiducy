# Attestation test fixtures

- `nitroDebugDocument.bin` is a real attestation document from a debug-mode AWS Nitro enclave, copied from the Apache-2.0 [aws-nitro-enclaves-attestation](https://github.com/ppmag/aws-nitro-enclaves-attestation) crate (`tests/data/nitro_ad_debug.bin`). It is signed by the real AWS Nitro root, has no nonce and all-zero PCRs.
- `anjunaProduction2021.bin`, `anjunaProductionWithPublicKey2021.bin`, `anjunaProduction2023.bin` and `anjunaDebugWithNonce2024.bin` are real attestation documents from the Apache-2.0 [go-nitro-attestation](https://github.com/anjuna-security/go-nitro-attestation) repository (commit `dc507eadb414`). The three production documents have real PCRs and no nonce; the debug one has the nonce `Nonce\n` and all-zero PCRs. Together they prove the chain checks (key usage, path length, critical extensions) accept real AWS chains from 2021 to 2024.
- `certificates.ts` holds a throwaway P-384 test root, intermediate and leaf (plus a leaf issued by a non-CA certificate) made with `openssl` for these tests only. Their private keys protect nothing.
- `chainCertificates.ts` holds more throwaway certificates under the same test root, each breaking one chain rule: a forged intermediate and leaf with copied names, a leaf whose issuer name differs from the key that signed it, a path length constraint exceeded, certificate authorities without `keyCertSign` or without key usage, unknown critical extensions, a signer that is not a certificate authority, an ECDSA SHA-256 signature and a repeated extension. All are valid for 100 years.
