Add `@fiducy/core/attestation`: `verifyNitroAttestation` checks an AWS Nitro Enclaves attestation document in the browser or on the server with WebCrypto only. It verifies the COSE_Sign1 signature, the certificate chain up to the pinned AWS Nitro root (CA flag, keyCertSign, path length and critical extensions), the nonce, that PCR0 and PCR16 are among the values you pass in `expectedPCR0s` and `expectedPCR16s` (both required, so the genuine image running someone else's deployment config is refused); it refuses debug-mode enclaves. The result carries `pcr0` and `pcr16` (`null` when the document has no PCR16). Errors include `unexpected_pcr16` and `webcrypto_unavailable` (no `crypto.subtle`, as on a plain-HTTP origin). Caller mistakes throw a `TypeError` instead: an empty nonce (send at least 16 random bytes), an empty `expectedPCR0s` or `expectedPCR16s`, or a value that is not a 96-character hex measurement. `encodeCBOR` is exported for the gateway's secure module requests.
