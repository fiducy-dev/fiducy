The setup prompt from `fiducy init` and `fiducy prompt` covers what an agent previously had to work out alone. Commands use your package manager and the pinned CLI version. Drizzle apps get `drizzle-kit push`, or `generate` + `migrate` when they keep migrations, plus the schema export line. The prompt explains that `fiducy dev` keeps running and writes `.env`, tells the agent to keep the app's model and request variable, mentions the now unused provider key, and ends with a done check.
